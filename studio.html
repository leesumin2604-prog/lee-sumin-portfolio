새 이미지 추가 방법: GitHub의 assets 폴더에 이미지를 업로드한 다음 여기서 이미지 경로를 assets/파일명.jpg처럼 입력하세요.

04 / CV

수상 · 활동 · 전시

각 행을 '연도 | 제목 | 세부 정보' 형식으로 입력하세요. 행 단위로 구분됩니다.

05 / PUBLISH

GitHub에 반영하기

  1. 내용을 수정하고 content.js 다운로드 버튼을 누르세요.
  2. GitHub 저장소의 맨 위 경로로 이동해 기존 content.js를 새 파일로 교체한 뒤 Commit changes를 누르세요.
  3. GitHub Pages를 켜 둔 경우 잠시 후 공개 사이트에도 수정한 내용이 반영됩니다.

그림을 바꿀 때는 assets/ 폴더의 해당 이미지를 교체하거나 새 이미지 이름을 등록하면 됩니다. 비밀번호나 GitHub 토큰을 이 화면에 입력할 필요가 없습니다.
